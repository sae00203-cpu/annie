# 앤도버 생활기록 · Firebase(클라우드) 설치 안내

학원 컴퓨터 없이 어디서나 쓰는 버전이에요. 처음 한 번, 30분 정도 걸려요.
무료 요금제(Spark)로 시작해요. 결제 카드는 필요 없어요.

## 1. Firebase 프로젝트 만들기
1. PC에서 https://console.firebase.google.com 에 **Annie 구글 계정**으로 들어가요.
2. **프로젝트 추가** → 이름 `andover-record` (다른 이름도 괜찮아요) → Google 애널리틱스는 **사용 안 함** → 만들기.

## 2. 로그인 방법 켜기
1. 왼쪽 **빌드 → Authentication → 시작하기**.
2. **로그인 방법** 탭에서
   - **이메일/비밀번호** → 사용 설정 → 저장 (선생님 아이디 + 개인 번호용)
   - **Google** → 사용 설정 → 지원 이메일에 Annie 이메일 → 저장 (관리자용)
3. **설정** 탭 → **승인된 도메인** → **도메인 추가** → `sae00203-cpu.github.io` 입력 → 추가.

## 3. 데이터베이스(Firestore) 만들기
1. 왼쪽 **빌드 → Firestore Database → 데이터베이스 만들기**.
2. 위치: **asia-northeast3 (서울)** → **프로덕션 모드**로 시작 → 만들기.
3. 위쪽 **규칙** 탭을 눌러, 안에 있는 글을 모두 지우고 저장소의 `cloud/firestore.rules` 내용을 붙여 넣어요.
4. 붙여 넣은 글에서 `ANNIE_EMAIL` 을 **Annie 구글 이메일**로 바꿔요. (따옴표는 그대로)
5. **게시** 를 눌러요.

## 4. 설정값을 Claude에게 보내기
1. 왼쪽 위 톱니바퀴 → **프로젝트 설정** → 아래 **내 앱** → **</> (웹)** 아이콘.
2. 앱 닉네임 `andover-web` → **앱 등록** (Firebase 호스팅은 체크하지 않아요).
3. 나오는 `firebaseConfig = { ... }` 안의 **apiKey, authDomain, projectId, appId** 네 줄을 복사해서 Claude에게 보내 주세요.
   - 이 값들은 비밀번호가 아니에요. 실제 보호는 로그인과 3번의 보안 규칙이 해요.

## 5. GitHub Pages 켜기 (이미 했다면 건너뛰기)
github.com/sae00203-cpu/annie → Settings → Pages → Branch `claude/academy-program-standalone-4mhcjb` · 폴더 `/docs` → Save.
나중에 PR 을 합치면 Branch 를 `main` 으로 바꿔요.

## 6. 처음 열기 (Claude가 설정값을 넣은 뒤)
1. **https://sae00203-cpu.github.io/annie/app/** 을 열어요.
2. **Google 계정으로 로그인** → Annie 계정 → **관리자로 등록** (한 번만).
3. 톱니바퀴 → **계정 · 데이터**
   - **학원 컴퓨터 데이터 옮기기**: 학원 컴퓨터 `andover-record/data/store.json` 파일을 골라요. (1,000개 넘으면 1분쯤 걸려요)
   - **+ 선생님 추가**: 이름 · 아이디(영어 소문자) · 개인 번호(6자리 이상)를 정해 선생님께 알려 드려요.
4. 선생님들은 같은 주소에서 **아이디 + 개인 번호**로 로그인하고, 휴대폰은 **홈 화면에 추가**해 두면 앱처럼 써요.

## 알아 두기
- **무료 한도**: 하루 읽기 5만 · 쓰기 2만 건. 기기마다 처음 한 번 전체 기록을 받고, 그다음부터는 바뀐 것만 받아서 보통은 넉넉해요.
  한도를 넘으면 그날은 저장이 멈출 수 있어요 → 그때 종량제(Blaze, 이 규모면 월 몇백~몇천 원)로 바꾸면 돼요.
- **백업**: 무료 요금제에는 자동 백업이 없어요. **계정 · 데이터 → 백업 파일 내려받기** 를 매주 한 번 해 두세요.
- **선생님이 개인 번호를 잊으면**: 그 계정을 **사용 중지**하고 새 아이디(예: `kate2`)로 다시 만들어요. 기록은 이름으로 남아 있어요.
- 학원 컴퓨터 버전은 옮기기 전까지 그대로 써도 돼요. 옮긴 뒤에는 한쪽에서만 입력해 주세요.
